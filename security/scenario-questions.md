# Security — Scenario Questions

**Label:** `Interview Preparation`

## Foundation
1. Explain the shared responsibility model and how it differs between IaaS and PaaS.
2. What's the difference between authentication and authorization, and where does each typically fail in real incidents?

## Intermediate
3. A team has been using a shared service account with broad permissions for convenience. Redesign their access model.
4. Design a secrets management strategy for a new microservices platform from scratch.

## Senior
5. A security audit finds 200+ hardcoded secrets across your application estate. Build a remediation plan.
6. How would you prevent privilege escalation via role/permission chaining in a cloud environment?
7. Design a defense-in-depth strategy for a dataset containing regulated customer data, assuming an attacker may obtain valid but limited credentials.

## Principal
8. How would you implement Zero Trust across Azure and GCP consistently, given a limited budget and existing legacy systems?
9. Design identity architecture for a multi-cloud enterprise with 5,000 employees and hundreds of workloads.
10. Your CSPM tool surfaces 3,000 findings and your security team can't triage them all manually. Build a prioritization and remediation strategy.

## Architecture Scenario
11. Design a security architecture for a greenfield fintech platform handling payment data, covering identity, network, data protection, and monitoring end to end.
12. A newly acquired company must be integrated into your security program within 6 months, starting from an unknown security posture. Plan the assessment and integration.
