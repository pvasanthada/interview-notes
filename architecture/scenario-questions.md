# Architecture & System Design — Scenario Questions

**Label:** `Interview Preparation`

## Foundation
1. Design a basic URL-shortening service, covering data model, scale estimate, and caching strategy.
2. Explain the difference between horizontal and vertical scaling and when each is appropriate.

## Intermediate
3. Design a rate limiter for a public API serving multiple tiers of customers.
4. A recently "cloud migrated" application still runs as fixed-capacity always-on VMs with tightly coupled synchronous calls. Redesign it to be cloud-native.

## Senior
5. Design a notification system that must reliably deliver messages across email, SMS, and push, with retry and dead-letter handling.
6. Design observability for a platform spanning multiple clouds and Kubernetes clusters.
7. Leadership wants to reduce cloud spend by 25% without degrading reliability. Build the plan.

## Principal
8. Design DR for a business-critical application with an RTO of 30 minutes and RPO of 5 minutes.
9. Design a multi-region, active-active e-commerce platform handling flash-sale traffic spikes.
10. Assess whether the organization should adopt a genuine multi-cloud resilience strategy following a competitor's cloud outage, and build the recommendation.

## Architecture Scenario
11. Design a complete system architecture for a ride-sharing platform's core dispatch system, covering data flow, scalability, consistency requirements, and failure handling.
12. Design an architecture governance model for an organization that has grown from 20 to 200 engineers in 18 months and has no formal architecture review process today.
