# Scenario Library — Cross-Domain

**Label:** `Interview Preparation`

This folder contains cross-domain, whiteboard-style scenarios that pull together multiple areas of this repository (cloud, Kubernetes, Terraform, security, FinOps, AI) — the kind of composite scenario a Principal Architect interview loop typically ends with.

Domain-specific scenario question *lists* live in each domain folder's own `scenario-questions.md` (e.g., [`azure/scenario-questions.md`](../azure/scenario-questions.md)). This folder instead contains a small number of **fully worked, cross-domain scenarios** using the [Scenario Framework](../docs/answering-frameworks.md#2-scenario-framework).
